## 自訂課程目錄（給不同班級）

在網址後加上 `?edit` 開啟選取面板，勾選單元、填標題後複製連結即可：<https://appjust.github.io/codex-courses/?edit>

- `?show=ai-levels,codex-intro`：只顯示這些單元
- `&title=…`、`&sub=…`：自訂標題與副標題
- `?set=名稱`：使用頁面程式中 `PRESETS` 預先存好的組合

字型：Inter、Noto Sans TC、Noto Serif TC（SIL Open Font License 1.1，經 Google Fonts 載入）。
